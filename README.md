# atbash-cipher

## Description
Atbash cipher is a method of encryption, which was invented circa 500 BC by Jewish scribes and scholars. They would mainly encode religious texts within the Hebrew Bible.

This application allows a user to encode and decode a message using Atbash cipher. This is completed by identifying each letter within a user’s message and then substituting its value with the opposite value within the alphabet.

## Requirements
This application was built using Python (v3.13) on Visual Studio Code.
